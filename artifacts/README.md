## 维护规则

- 日期回执只证明当次范围，不覆盖 PRD、实现状态或未来队列。
- 同一发布阶段的多份摘要合并为一个发布回执；专项机器回执可单独保留。
- 已解决的审计计划和逐阶段流水账删除，只保留仍有追溯价值的原始证据。
- 不写入真实业务数据、凭据、数据库、绝对外部路径或可恢复 Secrets。
- 易漂移的检查数、命令数和性能值只能写在日期回执或机器结果中。
