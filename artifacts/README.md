# AIBI-C 验收证据策略

`artifacts/` 不定义当前产品事实，也不长期归档可由当前自动化重建的截图、日志或发布回执。当前能力与限制见 [实现状态](../docs/implementation-status.md)，当前验收以对应提交上的 `npm run preflight` 输出为准。

## 保留条件

- 仅保留无法由当前代码和固定回归重建、且仍有独立审计价值的最小证据。
- 每份保留证据必须注明提交、范围、生成命令、数据边界和失效条件，并在本索引登记。
- 旧版本截图、被当前回归完整覆盖的回执、临时导出和调试日志应及时删除。
- 不写入真实业务数据、凭据、数据库、外部绝对路径或可恢复 Secrets。

当前没有需要长期保留的日期证据。
