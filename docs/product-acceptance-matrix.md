# AIBI-C 产品验收矩阵

本矩阵只描述用户可观察的稳定行为。实现细节和检查数量不在此维护；日期结果见 [验收证据索引](../artifacts/README.md)。

## 核心旅程

| 场景 | 操作 | 必须观察到 | 失败信号 |
| --- | --- | --- | --- |
| 空工作区 | 创建或打开无数据工作区 | 只引导接入真实数据；无图表、问题、业务结论或高级建模噪声 | 出现样例数据、默认问题、假指标或领域模板 |
| 接入真实来源 | 检查 external real file or folder | 预检识别来源类型并展示目标、字段、行数、键、冲突和影响；确认前不写入 | 直接写入、重复预演、读取未允许路径 |
| 生成证据 | 导入后生成证据摘要 | 展示当前来源、字段质量、关系候选、缺口与指纹 | 复用已失效 Run 或以历史结果替代当前证据 |
| 创建单图 | 描述一个明确指标和维度 | 直接得到一个可核对的结果或草案；来源、口径和写入目标清晰 | 创建多组件模板、隐藏聚合或静默选择歧义字段 |
| 确认写入 | 核对并确认草案 | 只有一个确认面；完成后打开真实对象并产生回执 | 重复确认、写入错误工作区或只显示临时成功提示 |
| 连续分析 | 从已确认结果继续比较 | 新分支保留父 Receipt、Unit、动作和拒绝历史 | 从未确认或失效结果无血缘继续 |

## 语义、跨表与领域边界

| 场景 | 必须观察到 | 失败信号 |
| --- | --- | --- |
| 业务问题理解 | “我理解的问题”区分指标、维度、实体、时间、总体、比较、粒度和输出，并能追溯 Structural、Semantic、Business、Operational、Behavioral 五层来源 | 从关键词直接选列，或用个人表达偏好覆盖共享业务口径 |
| 工作区上下文 | 证据页可查看当前 Workspace Manifest，数据工作台可查看字段画像；空工作区返回真实 incomplete/空目录，所有对象和状态只来自当前工作区 | 生成样例对象、读取其他工作区同名表，或让客户端 workspace 参数越过服务端隔离 |
| 字段画像与 PII | 类型、空值、基数、时间覆盖、候选来源、敏感性和 freshness 分层展示；只有手工或人工审核接受的语义显示 confirmed，敏感字段不显示原值，stale/blocked 画像不用于规划 | 把样例或自动候选当业务定义、候选授权 Join、暴露邮箱/手机号/路径，或继续使用失效画像 |
| 字段与口径歧义 | 展示表级候选、歧义类型、来源和选择影响；一次只问一个会最大幅度改变结果的问题，显式表名可消歧 | 按列顺序、导入顺序或模型偏好决胜，或同时抛出一串低价值问题 |
| 复合比率 | 没有已验证分子/分母时要求澄清 | 把退款率、转化率或占比退化为 `COUNT(*)` |
| 多维问题 | Receipt 保留全部指标、维度、筛选、参与表和粒度 | 只处理首个命中字段 |
| 安全跨表 | 一至三跳全局线性路径覆盖全部必需表并展示每跳粒度、版本、基数、筛选/预聚合和根到事实可达性；等价根表与同表异键路径均提供可选择入口，候选搜索未能证明穷尽时明确阻断，选择完整 `relationKey` 后保留原问题并继续；运行时覆盖筛选/预聚合时按最终形状重证；非 COUNT 空侧显示无数据；不安全路径阻断 | 给各表独立选择局部最短路径、把达到枚举上限误当作完整候选集、根表或路径按候选顺序静默决胜、歧义无可完成入口、推荐关系直接执行、旧扇出证明被复用、NULL 被伪装成零、one-side 指标重复、孤儿链静默漏数、失效关系或漂移 Receipt 继续使用 |
| 中性数据 | 无 Pack 时只出现结构事实 | 出现电商、ERP、资金、订单、售后或保单语义 |
| Pack 启停与冲突 | 显式预演和确认；启用只增加声明能力，停用恢复通用结果；冲突可解释 | 自动启用、按加载顺序决胜或改写历史结果 |
| 业务理解 Skill | 可查看命中的 Skill、版本、触发依据、缺失槽位和最终允许能力；同等级候选要求选择 | Skill 增加 Registry 外能力、携带 SQL/脚本/URL，或按文件顺序静默决胜 |
| 计划质量基准 | 设置页可运行固定中立 Case，并分别查看核心槽位、字段、澄清、证据和重放指标；评分不读取用户业务行、不调用 Provider，零容忍项均为 0，运行时或 Case Set 漂移后明确要求重跑 | 用 Provider 自评、生产数据抽样或旧评分冒充当前发布门禁，或把 stale 回执继续标为可发布 |
| 纠正与复用 | 用户纠正、数据字典和文档先形成带来源及 Before/After 的不可变提案；接受/拒绝先预演再确认，schema 或目标漂移后接受阻断；只有已确认且当前可用的结果可成为复用候选 | 聊天纠正自动写入共享事实、原始文档/路径进入配置、跨工作区生效、stale 提案被接受，或 stale 结果进入知识库 |

## 对象、安全与恢复

| 场景 | 必须观察到 | 失败信号 |
| --- | --- | --- |
| 路由恢复 | 刷新、前进、后退回到同一 `table`、`view`、`dashboard`、`run` 或 `action` | 跳到无关对象或保留不兼容上下文 |
| 删除来源或对象 | 先列出依赖和影响，确认后删除并返回回执；拒绝不改变状态 | 未预演删除、残留不可见引用或误删其他工作区 |
| Connector | 发现、预览、计划与确认导入分离；凭据仅显示是否配置 | 字面凭据泄露、任意网络/SQL、预览阶段写入 |
| Job 取消与重启 | 取消需确认且仅作用于登记 worker；重启中断形成可审计终态 | 静默重跑、越权终止进程或进度倒退 |
| 迁移与恢复 | 默认预演；确认前创建恢复点；失败恢复 SQLite 与 DuckDB | 原库在预演中变化、只恢复一库或无校验和 |
| 工作区隔离 | 用户工作区、临时验证工作区和历史证据互不串扰 | 测试输入进入用户空间或跨工作区“最新结果”复用 |
| Provider/Profile | 切换只改变解释层；Receipt、字段、Capability 和确认边界不变；故障自动降级，评估回执无原始行和凭据 | Provider 生成 SQL/字段、写草案、泄露原始行，或故障导致本地答案不可用 |
| 受限工作流 | Turn 可回读固定图、专家视图和 Join 结果；只读并行不改变公开事件顺序，专家失败降级为单 Orchestrator | 未知/任意 Operator 执行、专家调用工具、并行写入、循环重规划或指纹漂移后仍合并 |
| 规划指纹漂移 | 数据、schema、画像、指标、公式、关系、Context、Pack 或 Skill 变化后，旧计划/Receipt 明确 stale 或阻断并重新规划 | 只核对表名、忽略 Workspace Planning Binding，或用历史 Manifest 覆盖当前状态 |

## 界面与生产边界

| 场景 | 必须观察到 | 失败信号 |
| --- | --- | --- |
| 生产无演示数据 | 新工作区没有来自 `validation-inputs`、Fixtures 或测试脚本的可见内容 | 生产 UI 出现测试表、默认结论或示例提问 |
| 历史计划复用 | 用户显式提升成功分析后，用相同或改写问法再次分析 | 显示 Confirmed Plan 候选与 Recall Receipt；当前 Semantic Plan 与无记忆时一致；漂移后候选排除 |
| 响应式窗口 | 桌面和窄屏可访问工作区切换、全部主导航、高级工具和设置；无全局横向溢出 | 控件遮挡、正文逐字换行或靠隐藏核心入口适配 |
| 空看板 | 只创建看板容器，组件列表为空 | 自动注入指标、图表或领域模板 |
| 错误与空态 | 说明真实原因、影响和下一步；键盘焦点可达 | 只显示颜色、原始堆栈或无行动提示 |

## 自动化门禁

- `npm run verify:docs`
- `npm run build`
- `npm run verify`
- `npm run verify:ui`
- `npm run preflight`

交付前以完整 `preflight` 为准；专项验证只能证明对应改动面，不能替代总门禁。
