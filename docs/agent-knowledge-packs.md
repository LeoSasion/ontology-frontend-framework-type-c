# Agent 业务知识包

## 作用

Knowledge Pack 把已验证的业务粒度、状态、去重、连接和指标规则保存为版本化项目资产。它不是训练数据、提示词集合或固定业务答案；生产结果始终由当前工作区数据计算。

## 唯一事实源

当前知识包是 `knowledge/platform-commerce.v1.json`。JSON 维护规则、字段角色、只读查询、来源边界和版本；本文件只描述运行合同，不复制规则全文或数量。

## 运行合同

1. 先用当前工作区字段集合匹配表角色；结构不完整时不套用规则。
2. 再匹配窄业务意图；宽规则不得覆盖更具体的跨表口径。
3. 只执行仓库内审阅过的 `SELECT` / `WITH` 查询，表名只能来自当前工作区注册表。
4. 涉及未确认分子、分母、去重或连接粒度时阻断，不执行近似聚合。
5. 回答和 Query Plan Receipt 保留知识包、规则、粒度、参与表、筛选和证据引用。
6. Provider 可以解释结果，不能修改规则 SQL、跳过结构匹配、伪造回执或在阻塞时补数字。

## 当前覆盖

`platform-commerce.v1` 处理抖音、淘宝/天猫和聚水潭导出中的高风险方法：成功退款口径、主单去重、一单多包裹、虚拟商品例外、订单版本、可归属售后、物流异常和百分比阈值归一化。

公开资料只用于定义分析方法，不证明存在平台直连，也不替代最新官方接口文档。

## 变更要求

新增或修改规则必须同时提供：

- 字段角色与结构匹配条件；
- 明确统计粒度、状态、去重和连接口径；
- 只读 SQL 与白名单参数；
- 可复算正向、阻塞和不匹配测试；
- 来源、适用范围和版本变化说明。

禁止只增加提示词、固定答案或领域字段回退。
