# AIBI-C 产品需求

[产品定位](../PRODUCT.md) 定义方向；本文件只描述当前版本必须满足的用户结果、功能边界和发布条件。

## 用户结果

| 用户 | 必须能够 |
| --- | --- |
| 业务新手 | 导入本地表格，不学习 SQL 或建模即可得到第一个可信图表 |
| 结果使用者 | 看懂来源、口径、可信度、关系路径和缺口，并继续分析 |
| 数据维护者 | 按需维护语义、指标、关系、公式、视图和看板，不干扰默认路径 |
| 工作区所有者 | 预演并确认导入、保存、覆盖和删除，获得可追踪回执 |

## 默认流程

1. 创建或选择本地工作区。
2. 在 Sources 预览文件或文件夹的目标、合并、键和风险，再确认导入。
3. 系统生成字段、质量、关系和缺口证据。
4. 用户描述问题或图表；系统直接回答、形成一个草案，或集中澄清一次。
5. 只读结果直接展示；写入在唯一确认面批准或拒绝。
6. 完成后打开真实对象；后续比较只从已确认结果创建有血缘分支。

## 功能需求

### 工作区与导航

- 创建、选择和删除工作区；表、语义、关系、查询、看板、Job、回执和 Connector 均按工作区隔离。
- `table`、`view`、`dashboard`、`run`、`action` 使用可恢复 URL 上下文；刷新、前进和后退回到同一真实对象。
- 对象不存在时展示真实空态，不创建样例或猜测对象。
- 删除、覆盖和恢复先展示依赖与影响，再显式确认。

### 数据源与 Connector

- 稳定导入 CSV、XLSX、XLSM；旧 XLS 只承诺画像读取，写入前需转换。
- 文件夹导入按同类表分组，预览目标、行数、键质量、冲突和去重影响后再写入。
- 空工作区只引导导入，不显示业务结论、图表或高级维护工具。
- `local-tabular/v1` Adapter 只读发现和预览当前工作区登记的本地表格，限制为 100 MB、100 行、64 列、每单元格 512 字符。
- 跨工作区、符号链接链、其他 AIBI 仓库路径、未支持来源、任意查询和字面凭据在读取前阻断。
- 凭据只允许服务端 `env:NAME` 引用；公开响应只说明是否已配置，不返回引用名或值。
- Connector 同步默认只生成计划；真实导入复用现有 dry-run/confirm 边界，Adapter 不写业务数据库或产物。

### 语义、关系与查询

- 字段语义记录角色、用途、置信度和手工覆盖；自动能力排除内部 `__*` 字段。
- 同名或近义字段跨表竞争时，显式表名优先；证据不足时集中澄清一次，不按列顺序、导入顺序或模型偏好选择。
- 多维问题完整记录指标、维度、筛选、参与表和统计粒度，不只处理首个命中字段。
- 关系推荐结合值重叠、基数、复合键和行膨胀；推荐关系不等于执行关系。
- 跨表路径只使用当前工作区已保存且验证仍有效的关系，最多规划三跳。`stale`、`review-required`、版本不一致或有放大风险时阻断。
- 复合业务键作为整体保存和验证；右表预聚合必须覆盖完整连接键，筛选、聚合和操作符均使用白名单。
- 数据导入、覆盖或合并递增表版本并自动复验依赖关系；查询不得复用失效快照。
- 查询只接受白名单参数，返回 Query Plan Receipt，不接受任意 SQL。

### 通用内核与领域扩展

- 新工作区默认不启用任何 Domain Pack；Core 只推断结构角色，不静默注入电商、ERP、资金、订单、售后、保单或客户语义。
- Domain Pack 通过统一 Manifest 和注册表提供领域别名、指标、规则、分析单元与确认问法；启停按工作区预演、确认并写回执。
- Connector Adapter 只负责来源访问和确认导入，不隐式启用 Domain Pack；Domain Pack 也不声明连接凭据或直接访问来源。
- Agent、Source Intelligence、关系推荐、看板单元和前端入口读取同一工作区 Pack 运行上下文，不维护彼此分叉的领域常量。
- 多 Pack 冲突不得按注册或加载顺序静默决胜；显式选择和手工语义优先，仍有歧义时集中澄清一次。
- Pack 停用或版本变化后不重解释历史结果；依赖对象进入复核状态，旧证据保留创建时的 Pack 版本。
- 完整架构、迁移与隔离合同见 [通用领域扩展框架](extensible-domain-framework.md)。

### 图表、看板与体验

- 默认图表请求只创建一个指标卡、柱图、折线图、饼图、表格或文本洞察草案。
- 草案展示来源、字段、聚合、口径、证据、目标和写入影响；真实写入只确认一次。
- 筛选、样式、关系、组件维护、查询计划和技术回执默认收起。
- 创建空看板只创建容器，不注入组件。
- 整套领域方案保持 Beta；仅在对应 Pack 已启用时出现，写入前披露命中单元、省略单元、字段缺口和来源。

### Agent、证据与连续分析

- 本地确定性运行时负责字段、查询、结果和证据；可选 Provider 只能解释或澄清，不拥有工具权限。
- 只读回答不创建动作草案；写入意图只生成待确认草案。
- Query Plan Receipt 保存来源、字段候选与选择、粒度、关系路径、运行时、验证、语境、未决项和动作关联，不保存模型私有推理。
- 已执行查询形成绑定 Receipt 的 Analysis Unit；只冻结规范化标量结果、结果指纹、形状、计算和验证，最多 500 行。
- Chart Adapter 只按 Unit 类型和数据形状选择白名单图表；不兼容或样本不足时解释性阻断。
- 已验证 Receipt/Unit 可导出确定性 ZIP、XLSX、Markdown 报告、脱敏快照、缺口和哈希 manifest；导出不重新查询或写业务库。
- 可信术语、规则和确认问法必须有作用域、证据和版本；结构变化后失效。
- 分析分支只能从已确认结果创建，并保留父结果、查询、动作和拒绝历史。

### Job、Workflow 与能力边界

- 超过短请求生命周期的分析创建工作区隔离 Durable Job，公开状态、阶段、单调进度、有序事件、结果、错误、产物和证据。
- 取消必须预演并确认，只作用于 AIBI-C 登记 worker；重启中断形成可审计终态，不静默重跑。
- Agent、API、CLI 和 Job 复用同一 Capability Contract；未知能力、禁止入口和越权资源在执行前阻断。
- 每次确定性命令输出可序列化 Workflow Stage，包含能力、输入/证据指纹、状态、产物、错误和恢复信息。
- Provider Context Budget 优先保留阻塞原因、口径、Receipt、确认边界和证据引用；必需上下文超限时停止 Provider。

### 本地运行与安全

- API 与 UI 只监听回环地址；请求体有上限，CORS 只允许一个显式来源。
- SQLite 元数据和 DuckDB 分析库使用显式版本；启动前只读检查兼容性。
- 迁移先验证隔离副本，确认前创建校验和恢复点；应用或复检失败时恢复双库。
- 备份不包含 `.env`、源文件、业务导出或凭据。

## 发布条件

- 仓库隔离门禁通过，默认构建、验证和运行不读取其他 AIBI 工作树。
- `npm run preflight` 通过，作为本地交付前总入口。
- [产品验收矩阵](product-acceptance-matrix.md) 中的稳定场景全部通过。
- 新工作区为空，生产 UI 不出现测试素材、默认问题或默认业务结论。
- 无 Pack 的中性数据集不出现领域词、领域缺口或领域模板；Pack 启停、并存与版本失效场景通过。
- 浏览器验收覆盖真实导入、单图、证据、确认、语义跨表、Connector 预演、对象路由恢复和常见 PC 比例。
- 数据迁移、备份恢复、Provider 降级、Job 取消/恢复、Analysis Unit 复算和导出脱敏均通过正向与阻塞验证。
