# AIBI-C Product Requirements

`PRODUCT.md` 定义产品方向；本文件只定义当前版本必须满足的用户结果与发布条件。

## User Outcomes

| User | Must be able to |
| --- | --- |
| 业务新手 | 导入本地表格，不学习 SQL 或建模即可得到第一个可信图表 |
| 结果使用者 | 看懂来源、口径、可信度和缺口，并从原对象继续分析 |
| 数据维护者 | 按需维护语义、指标、关系、公式、视图和看板，不干扰新手主流程 |
| 工作区所有者 | 预演并确认导入、保存、覆盖和删除，获得可追踪回执 |

## Primary Workflow

1. 创建或选择本地工作区。
2. 在 Sources 选择文件或文件夹，预览合并与影响后确认导入。
3. 系统生成字段、质量、关系和缺口证据。
4. 用户描述一个图表或业务问题；系统直接形成草案或最多澄清一次。
5. 用户查看业务结果与证据，需要写入时在唯一确认面批准或拒绝。
6. 完成后打开真实创建的对象；后续比较从已确认结果创建有血缘的分支。

## Functional Requirements

### Workspace And Navigation

- 支持创建、选择和删除工作区；所有业务对象按工作区隔离。
- `table`、`view`、`dashboard`、`run`、`action` 使用可恢复 URL 上下文。
- 刷新、浏览器历史和跨页完成跳转必须回到同一真实对象，不得用样例或猜测对象兜底。
- 删除工作区或对象前展示依赖与影响，确认后返回最近的有效对象。

### Sources And Semantics

- 稳定导入支持 CSV、XLSX、XLSM；旧 XLS 仅承诺证据画像读取。
- 文件夹导入按同类表分组，预览目标表、行数、键质量、冲突和去重影响后再写入。
- 空工作区只显示导入路径，不展示图表、业务结论或高级维护工具。
- 字段语义包含角色、用途、置信度和手工覆盖；自动能力排除内部 `__*` 字段。
- 关系推荐结合真实值重叠、基数与连接膨胀风险；自动清理不得删除手工资产。

### Query, Views And Dashboards

- 查询只接受白名单参数，支持明细、分组聚合、指标和受控关系查询，并返回运行回执。
- 保存视图只在 Details 创建、复制、查询和删除，其他页面携带上下文使用。
- 默认图表请求只创建一个指标卡、柱图、折线图、饼图、表格或文本洞察草案。
- 模糊请求最多澄清一次，并提供可点击的指标和维度候选；不得静默猜行业字段。
- 图表草案展示数据表、字段、聚合、口径、证据、目标看板和写入影响。
- 筛选、样式、关系、组件与页面管理按需展开；创建空看板时不得注入默认组件。
- 整套行业看板保持 Beta，写入前披露命中单元、省略单元、字段缺口和来源。

### Agent, Evidence And Continuity

- 只读回答不创建动作草案；写入意图只能生成待确认草案。
- Agent 披露确定性本地逻辑或可选模型的实际运行方式，密钥不越过服务端边界。
- Evidence 默认展示业务摘要、可信度和缺口，原始回执与诊断按需展开。
- 每次查询生成 Query Plan Receipt，记录来源、字段、运行时、验证、语境命中、未决项与动作关联，不保存模型私有推理。
- 可信术语、规则和确认问法必须有作用域与证据；结构或确认语义变化后相关记忆失效。
- 证据导出复用既有回执，不重新计算，不包含数据库、凭据、绝对路径或无关原始行。
- 分析分支只能从已确认结果创建，并保留父结果、查询、动作和拒绝历史。

### Local Operations

- API 与 UI 只监听回环地址；请求体有上限，错误响应区分无效 JSON 与超限请求。
- 本地数据库支持校验和备份、恢复预演、确认恢复与恢复前安全副本。
- 备份不得包含 `.env`、源文件、业务导出或凭据。

## Release Acceptance

- `npm run preflight` 通过，作为本地交付前总入口。
- `docs/product-acceptance-matrix.md` 的稳定场景全部通过。
- 新工作区为空，生产 UI 不出现测试素材、默认问题或默认业务结论。
- 浏览器验收覆盖真实导入、单图、证据、确认、对象级路由恢复和三种 PC 比例。
- CI 在 Windows 上通过构建、核心契约、生产安全、备份恢复与浏览器 smoke。
