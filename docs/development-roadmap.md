# AIBI-C 未来开发队列

本文件是唯一未交付工作队列。当前能力见 [实现状态](implementation-status.md)，产品边界见 [PRODUCT](../PRODUCT.md)。

## 先记住一条主流程

默认路径始终是：`导入真实数据 -> 生成证据 -> 描述问题或图表 -> 核对结果 -> 确认写入`。

未来能力不得增加默认路径步骤，也不得把高级配置提前展开。

## 当前队列

### P2. 更复杂的跨表执行

目标：在可证明粒度安全的前提下扩展当前一跳和线性正向两跳能力。

- 研究三跳、反向路径、跨跳筛选和预聚合的静态安全合同。
- 增加 fan-out、复合键变化、迟到维度和版本漂移的阻断/复算测试。
- 不因“查询能运行”而放宽默认执行；无法证明时继续返回澄清或阻断。

退出条件：新路径具有确定性计划、数据版本绑定、膨胀证明和浏览器可解释回执。

## 明确暂时不做

- 云端账号、多人协作、远程托管、多租户和隐藏遥测。
- 预置行业样例、默认问题、默认结论或假数据。
- 任意 SQL、任意代码执行、模型自主工具循环或隐式写入。
- 默认展开字段、关系、公式、布局和技术回执。
- 因单一客户数据可运行就固化行业模板。

## 维护规则

- 只保留未交付事项、顺序和退出条件。
- 交付后从本文件移除，并把稳定边界写入实现状态和验收矩阵。
- 不复制验证命令、脚本清单、日期回执或版本历史。
