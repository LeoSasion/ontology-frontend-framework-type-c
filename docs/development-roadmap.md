# AIBI-C 未来开发队列

本文件是唯一未交付工作队列。当前能力见 [实现状态](implementation-status.md)，产品边界见 [PRODUCT](../PRODUCT.md)。

## 先记住一条主流程

默认路径始终是：`导入真实数据 -> 生成证据 -> 描述问题或图表 -> 核对结果 -> 确认写入`。

未来能力不得增加默认路径步骤，也不得把高级配置提前展开。

## 当前队列

### 1. 整套行业看板 Beta 晋级条件

目标：只有当整套看板的证据、通用性和交互稳定性达到单图标准时，才评估晋级。

- 多个独立业务领域持续通过，不引入领域默认字段或隐藏模板。
- 缺字段单元始终省略并解释，不渲染为确定结果。
- 预演、确认、拒绝、回执和对象路由复用稳定写入边界。
- 默认入口仍是一问一图，新手第一屏不增加负担。
- 性能、视觉和可恢复性达到当前发布基线。

退出条件：重复真实数据回归和浏览器闭环都满足以上约束，再提交单独的产品晋级决策；技术可运行不能替代产品晋级。

## 明确暂时不做

- 云端账号、多人协作、远程托管、多租户和隐藏遥测。
- 预置行业样例、默认问题、默认结论或假数据。
- 任意 SQL、任意代码执行、模型自主工具循环或隐式写入。
- 默认展开字段、关系、公式、布局和技术回执。
- 因单一客户数据可运行就固化行业模板。

## 维护规则

- 只保留未交付事项、顺序和退出条件。
- 交付后从本文件移除，并把稳定边界写入实现状态和验收矩阵。
- 不复制验证命令、脚本清单、日期回执或版本历史。
