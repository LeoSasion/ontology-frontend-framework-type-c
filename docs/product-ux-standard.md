# AIBI-C 产品体验标准

本文件只维护可观察的交互与信息架构约束；功能范围见 [PRD](PRD.md)，验收场景见 [产品验收矩阵](product-acceptance-matrix.md)。

## 体验原则

- 默认路径是一问一图；字段不明确时最多集中澄清一次。
- 第一屏依次展示当前意图、结果或草案、最小信任摘要和一个下一步。
- 无数据时只引导导入；不加载样例、默认问题、行业字段或预设结论。
- 只读、解释、证据和预演无需确认；真实写入只有一个确认面。
- 高级维护和技术回执按需展开，不与当前任务竞争视觉优先级。

## First Success Flow Standard

`Sources 导入 -> 自动生成证据 -> Dashboards 创建一个图表 -> Evidence 核对 -> AI 确认或拒绝写入`

只突出当前可执行步骤。前置条件未满足时不展开后续完整控件；激活进度由共享状态维护，各页面不得各写一套引导。

## Object Ownership Matrix

| 对象 | 主页面 | 其他页面行为 |
| --- | --- | --- |
| 数据表、导入、字段、指标、关系、公式、Connector | Sources | 显示摘要并跳转 |
| 保存视图 | Details | 携带上下文使用 |
| 看板、页面、组件 | Dashboards | 显示结果、链接或证据摘要 |
| 查询、证据和运行回执 | Evidence | 显示最小可信状态并可展开 |
| 动作草案、确认与拒绝 | AI | 其他页面只显示待处理状态 |
| 工作区、配置、术语、规则和确认问法 | System | AI/Evidence 只显示命中摘要 |

创建、编辑和删除留在对象主页面；其他页面通过对象上下文跳转，不复制操作。

## 路由与空态

- URL 只携带完成下一步所需的 `table`、`view`、`dashboard`、`run`、`action`。
- 刷新、后退和前进恢复同一对象；对象不存在时展示真实空态，不创建 fallback。
- 导入后打开真实表，确认图表后打开真实看板，Evidence 返回来源对象或沿同一 Receipt 继续分析。
- 首页只定位和跳转，不直接执行扫描、模板、Agent 问题或确认。
- 空态只有一个主要动作，侧栏不重复主内容的下一步。
- Creating an empty dashboard creates only the dashboard container. 组件必须来自真实字段证据或明确草案。

## 渐进展示与文案

- 默认收起筛选、关系、样式、组件维护、查询计划、原始 SQL、可信语境、确认问法、分析分支和验证工具。
- 已确认结果才显示“继续比较”；阻塞、待确认或被拒绝结果不能成为分支父节点。
- 主界面使用结果导向文案，不暴露 payload、module、内部 ID 或原始浮点数。
- 状态必须说明发生了什么、是否写入、下一步是什么。
- 横向空间不足时减少并列列数，优先保持正文、按钮和状态完整，禁止逐字换行。

## 确认标准

| 动作 | 交互 |
| --- | --- |
| 只读回答、解释、证据、预演 | 不确认，并说明未写入 |
| 普通写入 | 一个确认面，展示目标、影响、证据和拒绝路径 |
| 覆盖、删除、恢复 | 先预演依赖与影响，再显式确认 |

## Delete And Rollback Standard

- 删除入口位于对象主页面的折叠管理区。
- 预演展示目标、依赖、影响和写入状态；确认后显示回执并跳转到最近有效对象。
- 尚未写入的草案以拒绝作为回滚路径，不增加第二次确认。

稳定 UX 行为只在 `docs/product-acceptance-matrix.md` 验收；本文件不记录截图、修复过程或组件文件清单。
